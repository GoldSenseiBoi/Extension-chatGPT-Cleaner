✅ Étapes pour récupérer le token Bearer dans Chrome

  1. Va sur https://chatgpt.com
    → Assure-toi d’être connecté à ton compte OpenAI.
  2. Ouvre DevTools (F12 ou clic droit > Inspecter)
  3. Va dans l’onglet Network
  4. Recharge la page (F5)
  5. Dans la liste des requêtes, cherche ou filtre une ligne vers : 
    https://chatgpt.com/backend-api/conversations
  6. Clique dessus → Va dans l’onglet Headers
  7. Descends dans la section Request Headers
  8. Tu verras une ligne comme : 
    Authorization: Bearer eybiOi...
  9. ✅ Copie la partie après "Bearer" (c’est le token)
