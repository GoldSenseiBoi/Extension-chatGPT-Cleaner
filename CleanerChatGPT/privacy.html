Privacy Policy – CleanerChatGPT

Effective Date: 24/05/2025

Overview

CleanerChatGPT does not collect or transmit any personal data. All data remains local on the user’s browser. The extension interacts only with https://chatgpt.com to access the user's conversations via OpenAI's API.

Permissions Usage

  • activeTab: To inject scripts into the ChatGPT tab for retrieving access tokens.
  • cookies: To read session cookies required to extract the Bearer token (locally only).
  • scripting: To run a content script that captures token information from the webpage.
  • storage: To save the Bearer token locally and persist it across browser sessions.
  • webRequest & webRequestBlocking: To intercept and extract the Authorization header from legitimate requests to OpenAI's backend.
  • host_permissions (chatgpt.com): Required to call the ChatGPT backend API directly.

Code Execution

All code runs locally. No external scripts are fetched or executed dynamically.

Data Collection

No user data is collected, transmitted, or shared. All operations remain local to the user's browser session.
